# Proxy & Bridge Patterns — Java Lab

All six tasks from the supplied worksheet are implemented in `Main.java` using plain Java and no external libraries.

## Run

```bash
javac Main.java
java Main
```

## Tasks

1. Protection Proxy: denies non-admin access before creating the real image.
2. Logging Proxy: counts video plays and lazily downloads only once.
3. Firewall Proxy: blocks gaming.com and socialmedia.com.
4. Bridge: SmartLight works with AdvancedRemote without changing the remote.
5. Bridge: PartyRemote works with Radio without changing the device.
6. Bridge: Knight and Wizard can use any Weapon implementation.
